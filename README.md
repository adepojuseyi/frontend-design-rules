# Frontend Design Rules

A reusable AI skill that helps coding agents apply practical visual design principles when creating, reviewing, and improving frontend interfaces. The goal is to encourage thoughtful design decisions, not make every interface look the same.

## Installation

Install using the [Skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add adepojuseyi/frontend-design-rules
```

Follow the prompts to select your preferred AI coding agent.

## Usage

Ask your AI coding agent to use the skill when building or improving an interface.

Example:

> Use the frontend-design-rules skill to build a landing page hero. Apply the visual hierarchy principle while considering the product's audience and visual identity.

## Updating

To retrieve the latest published rules and improvements, run:

```bash
npx skills update
```
