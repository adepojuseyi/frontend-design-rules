# Usage

## Apply the Skill

Describe the UI you want and explicitly request the skill.

Example:

> Build a SaaS landing page hero using the frontend-design-rules skill. Apply visual hierarchy and explain which elements are primary, secondary, and supporting.

## Review an Existing Interface

> Review this component using the frontend-design-rules skill. Identify relevant rules, explain any violations, and improve the implementation where necessary.

## Keep Rules Updated

Run `npx skills update` to retrieve available updates to installed skills.

## Important

The skill guides design decisions; it does not guarantee perfect results. Review generated interfaces for usability, accessibility, responsiveness, and consistency with your project's existing design system.
