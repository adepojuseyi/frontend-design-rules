# Anchor Effect

## Principle

Elements positioned near the edges of a layout can appear accidentally cropped, awkwardly aligned, or visually disconnected if their placement lacks intention. Edge placement should communicate a deliberate design decision rather than look like a mistake.

## When to Use

Apply this principle when designing or reviewing:
- Hero sections with text or imagery near the viewport edges
- Full-bleed images and backgrounds
- Navigation bars and floating controls
- Editorial and asymmetrical layouts
- Cards, illustrations, and decorative elements that extend beyond containers
- Responsive layouts where content approaches or crosses screen boundaries

## How to Apply

- Decide whether an element should sit inside the content area, align with its edge, or intentionally extend beyond it.
- Use consistent alignment and spacing to make edge placement feel deliberate.
- When an element intentionally bleeds beyond a container, ensure the crop or overflow supports the composition.
- Use clipping, masks, or container boundaries only when they serve the design.
- Check edge placement at different viewport sizes to prevent accidental clipping or horizontal overflow.
- Preserve readable margins for text and interactive controls, especially on small screens. 

## Do

- Use edge alignment to establish structure or create visual tension when appropriate.
- Make intentional cropping visually coherent.
- Maintain enough breathing room for important text and controls.
- Check how edge-positioned elements behave responsively.
- Consider whether an element's proximity to the edge reinforces the intended visual direction.

## Don't

- Push elements against edges simply to make a layout feel more dramatic.
- Leave text, buttons, or essential content awkwardly clipped.
- Use negative margins or overflow without understanding their effect on other viewport sizes.
- Assume every element near an edge needs to extend beyond it.
- Confuse deliberate asymmetry with inconsistent spacing.

## Exceptions

Full-bleed imagery, immersive experiences, carousels, decorative illustrations, and asymmetrical editorial layouts may intentionally use edge-to-edge composition or cropping. These treatments are appropriate when they support the intended experience and do not interfere with usability.

## Validation

- Does edge placement look intentional?
- Are alignment and cropping visually coherent?
- Are important elements readable and accessible?
- Does the layout behave correctly on mobile and desktop?
- Does the composition benefit from the edge placement, or would additional spacing improve it?

The goal is to use edges intentionally, not to force every interface into the same margins or layout.
