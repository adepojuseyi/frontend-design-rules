# Modular Grids

## Principle

A modular grid organizes a layout into a structured system of columns and rows, creating consistent spaces for content and visual elements. It provides a foundation for alignment, spacing, and visual hierarchy without requiring every section to look identical.

Grids should support the content and purpose of an interface, not constrain every design to a rigid template.

## When to Use

Apply this principle when designing or reviewing:
- Dashboards and data-heavy interfaces
- Product listings and card layouts
- Editorial and content-rich pages
- Image galleries and portfolios
- Landing pages with multiple content sections
- Responsive layouts with repeated components

## How to Apply

- Identify the content groups and relationships that need structure.
- Choose an appropriate number of columns and rows for the layout.
- Define consistent gutters and spacing between grid areas.
- Align related elements to shared grid lines where it improves clarity.
- Use different grid areas or spans to establish visual hierarchy.
- Adapt the grid to the content and viewport rather than forcing every element into equal-sized cells.
- Reassess the grid at different screen sizes to maintain readability and usability.

## Do

- Use grids to create consistent alignment and spacing.
- Allow important content to occupy more space when appropriate.
- Use grid areas and spans to create visual rhythm and emphasis.
- Maintain clear relationships between related sections.
- Combine grid structure with whitespace and typography to support hierarchy.
- Choose CSS Grid or another suitable layout method based on the implementation needs.

## Don't

- Force every component into an identical-sized grid cell.
- Add unnecessary rows or columns just to make a layout appear structured.
- Let the grid override the natural order or importance of content.
- Sacrifice responsive behavior to preserve a desktop composition.
- Assume that a more complex grid produces a better design.
