# Column Grids

## Principle

A column grid divides a layout into vertical columns that help organize content, establish alignment, and create consistent spacing. It provides a practical way to structure complex interfaces while allowing elements to vary in width and prominence.

The right column structure depends on the content, viewport, and intended experience.

## When to Use

Apply this principle when designing or reviewing:
- Landing pages and marketing websites
- Multi-column content sections
- Dashboards and admin interfaces
- Product listings and search results
- Editorial layouts and portfolios
- Responsive page structures

## How to Apply

- Determine the type and amount of content the layout needs to accommodate.
- Choose a suitable column count for the available space.
- Establish consistent gutters and page margins.
- Align related components to shared columns when it improves readability.
- Allow elements to span multiple columns according to their importance and content needs.
- Use fewer columns on smaller screens when necessary.
- Reflow content in a logical order on mobile rather than simply shrinking the desktop layout.

## Do

- Use columns to establish clear alignment and predictable structure.
- Keep gutters and margins consistent where appropriate.
- Vary column spans to create hierarchy and visual interest.
- Match the grid to the content rather than selecting a column count arbitrarily.
- Test the layout at different viewport widths.
- Use semantic document structure and accessible reading order alongside visual layout.

## Don't

- Force all content into equal-width columns.
- Use a twelve-column grid simply because it is common in web design.
- Allow narrow columns to make text difficult to read.
- Preserve desktop column arrangements when they no longer suit mobile screens.
- Use visual positioning that creates a confusing reading order for keyboard or assistive technology users.

## Exceptions

Single-column layouts are often better for focused reading, simple forms, narrow screens, and content that benefits from a clear linear flow. Asymmetrical layouts may also use columns selectively rather than applying a uniform grid across the entire page.

## Validation

- Does the column structure make the page easier to scan?
- Are content widths appropriate for their purpose?
- Are margins and gutters visually consistent?
- Does the layout establish hierarchy rather than create unnecessary uniformity?
- Does content reflow naturally on smaller screens?
- Does the visual arrangement preserve a logical and accessible reading order?

The goal is to organize content with intention and flexibility, choosing a column structure that supports the needs of each interface.
