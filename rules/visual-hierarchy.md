# Visual Hierarchy

## Principle

Create a clear order of importance between elements so the user's eye knows what to notice first.

## When to Use

Apply this when designing sections that contain multiple elements competing for attention.

## How to Apply

Use three levels of emphasis:

1. One dominant element
2. One or two secondary elements
3. Remaining elements as supporting content

Create hierarchy through:

- Size
- Weight
- Contrast
- Spacing
- Position
- Color

## Do

- Make the most important element visually dominant.
- Give secondary elements noticeably less emphasis.
- Keep supporting elements visually subordinate.
- Make the intended reading order obvious.

## Don't

- Give multiple unrelated elements equal visual weight.
- Make every element large or bold.
- Use color alone to establish hierarchy.

## Exceptions

Hierarchy can change when elements have equal importance, such as comparison tables or evenly weighted navigation items.

## Validation

Ask:

"What does the user notice first?"

If the answer isn't obvious, strengthen the visual hierarchy.
